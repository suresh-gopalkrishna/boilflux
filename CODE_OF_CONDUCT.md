# Code of Conduct

BoilFlux is a scientific community project. We want it to be welcoming to researchers,
engineers and students of every background and level of experience.

## Expected behaviour

- Be respectful and constructive in issues, reviews and discussions.
- Critique ideas and results, not people.
- Give credit: cite the work, data and code you build on.
- Assume good faith and help newcomers.

## Unacceptable behaviour

- Harassment, insults, discriminatory language or personal attacks.
- Publishing others' private information without permission.
- Plagiarism or misrepresenting others' data or results.

## Enforcement

Report concerns privately to the maintainers at **boilflux@itr-research.example** (replace with
the project contact address). Maintainers will review every report, keep it confidential, and may
warn, temporarily ban or permanently ban participants who violate this code.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
